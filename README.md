🍔 Online Food Order Simulation System (C)

A console-based C project that simulates a simple online food ordering system.
Users can view a menu, place multiple food orders, and generate a final bill.

This project is ideal for beginners, college mini-projects, and learning core C concepts.

🚀 Features

Menu-driven interface

Multiple food item selection

Quantity-based billing

Final bill calculation

Simple and beginner-friendly logic

🛠 Tech Stack

Language: C

Compiler: GCC / Dev-C++ / Turbo C

Platform: Console (Terminal)
